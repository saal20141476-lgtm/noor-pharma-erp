# دفتر الحسابات — النسخة الأولية

واجهة عربية RTL مستوحاة من فئة تطبيقات دفاتر الحسابات، وليست نسخة من الكود الأصلي.

## ما يعمل محليًا
- إضافة وتعديل وحذف الحسابات.
- تسجيل ديون ومقبوضات ومدفوعات.
- حساب الرصيد تلقائيًا لكل حساب ولكل عملة منفصلة.
- البحث والتصفية بالتاريخ.
- كشف الحساب والتقارير الأساسية.
- تصدير العمليات CSV، والطباعة أو الحفظ PDF من نافذة الطباعة.
- نسخ احتياطي JSON واستعادة نسخة.
- واجهة PWA قابلة للتخزين المؤقت للعمل دون إنترنت بعد أول تحميل عبر HTTPS.

## تشغيل نسخة الويب
يتطلب Node.js 20+:
```bash
npm install
npm run build
npm run start
```
انشر محتويات `dist/` على استضافة HTTPS تدعم المواقع الثابتة.

## بناء APK من الهاتف عبر GitHub Actions
1. ارفع كل ملفات هذا المشروع إلى مستودع GitHub جديد، بما فيها المجلد `.github/workflows`.
2. افتح تبويب Actions في المستودع.
3. اختر Build Android APK ثم Run workflow.
4. بعد نجاح البناء افتح تشغيل Workflow ونزّل Artifact باسم `daftar-hisabat-debug-apk`.
5. فك ضغط Artifact لتحصل على `app-debug.apk`. هذا APK تجريبي غير موقّع للنشر التجاري؛ اختبره على جهازك.

ملف APK لم يُبنَ داخل حزمة المصدر هذه ولم يُختبر على جهاز فعلي.

## المزامنة بين الويب وAndroid
التخزين المحلي جاهز. المزامنة الحقيقية تحتاج إعداد مشروع Supabase مشترك:
1. أنشئ مشروع Supabase.
2. نفّذ `supabase.sql` في SQL Editor.
3. أدخل Project URL وanon/public key ومعرّف الدفتر نفسه على الويب وعلى APK.
4. اضغط «مزامنة الآن».

**تحذير خصوصية:** سياسة SQL المرفقة للاختبار فقط وتسمح لأي شخص لديه رابط المشروع ومفتاح anon بالوصول إلى الدفتر. لا تدخل بيانات عملاء حقيقية قبل إعداد تسجيل دخول وسياسات وصول خاصة بالمستخدمين. كما أن المزامنة الأولية تستخدم نسخة الدفتر كاملة، وليست مزامنة متقدمة لحل التعارضات أو دمج تعديلات متزامنة متعددة.

## تنبيهات محاسبية
- لا تُجمع العملات المختلفة في إجمالي واحد.
- «دين لصالحنا» يزيد المبلغ المستحق لنا؛ «دين علينا» يقلله.
- «مقبوضات/سداد لنا» تخفض رصيد العميل المستحق لنا، و«مدفوعات/سداد منه» تخفض التزامنا له وفق نموذج الحساب المبسط.
- احفظ نسخة احتياطية بانتظام.
